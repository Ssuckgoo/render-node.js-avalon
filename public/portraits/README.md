# 역할 일러스트 넣는 곳

이 폴더에 그림 파일을 넣으면, 코드로 그린 기본 초상 대신 그 그림이 금테 메달 안에 표시됩니다.
코드를 고칠 필요는 없고, 파일을 넣고 서버를 다시 띄우거나(로컬) 푸시하면(Render) 반영됩니다.

## 파일 이름

역할마다 아래 이름으로 넣습니다. 확장자는 `.webp`, `.png`, `.jpg` 중 아무거나 됩니다.
일부 역할만 넣어도 되고, 없는 역할은 기본 초상이 나옵니다.

| 파일 이름 | 역할 |
|---|---|
| `merlin` | 멀린 |
| `percival` | 퍼시벌 |
| `servant` | 아서의 충신 |
| `assassin` | 암살자 |
| `morgana` | 모르가나 |
| `mordred` | 모드레드 |
| `oberon` | 오베론 |
| `minion` | 모드레드의 하수인 |

## 그림 규격

- **정사각형**, 512×512 이상을 권합니다. 화면에서는 원형으로 잘려 보입니다.
- **얼굴과 상반신을 가운데**에 둡니다. 네 귀퉁이는 원 밖으로 잘립니다.
- 파일 하나에 200KB 이하를 권합니다. `.webp` 로 저장하면 용량이 가장 작습니다.
- 테두리는 넣지 않습니다. 금테는 화면에서 자동으로 둘러집니다.

## 저작권

보드게임 "레지스탕스: 아발론"의 공식 일러스트는 저작권이 있으므로 쓰면 안 됩니다.
직접 그리거나, AI 이미지 생성기로 만들거나, 사용이 허락된 그림을 쓰세요.
