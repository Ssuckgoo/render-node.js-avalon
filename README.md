# 아발론

Render 무료 티어에 올릴 수 있는 5~10인 온라인 아발론입니다. (Node.js + Express + Socket.IO)

역할 배정·투표·원정 진행과 방 안 텍스트 채팅을 제공합니다. 음성 대화는 없으므로, 말로 토론하려면 한자리에 모이거나 디스코드 같은 음성 통화를 같이 쓰면 됩니다.

## 제한 시간

방장이 로비에서 두 가지를 따로 정합니다. 선택지는 제한 없음(기본), 30초, 1분, 2분, 3분, 5분입니다.

| 설정 | 적용되는 단계 | 시간이 지나면 |
|---|---|---|
| 원정대 구성 · 암살 | 리더가 원정대를 고를 때 | 부결 1회로 치고 다음 리더로 넘어감 |
| | 암살자가 멀린을 지목할 때 | 선의 승리 |
| 투표 · 원정 카드 | 찬반 투표 | 안 낸 사람은 찬성으로 처리 |
| | 원정 카드 제출 | 안 낸 카드는 성공으로 처리 |

- 시간은 서버가 잽니다. 남은 시간은 원탁 한가운데에 표시되고, 10초 이하가 되면 붉게 깜빡입니다.
- 제한 시간을 걸어 두면 접속이 끊긴 사람 때문에 게임이 멈추지 않습니다.
- 자동 처리된 내용은 다음 단계 안내 위에 표시됩니다.

## 캐릭터 설명

입장 화면과 대기 화면에서 캐릭터 초상을 누르면 그 캐릭터가 아는 것, 능력, 요령을 담은 설명 창이 뜹니다.

## 채팅

- 같은 방 사람끼리만 주고받습니다. 휴대폰에서는 오른쪽 아래 버튼으로 열고, 넓은 화면에서는 오른쪽에 항상 펼쳐져 있습니다.
- 방마다 최근 100개를 메모리에 보관해, 나중에 들어오거나 재접속한 사람에게도 보여 줍니다. 서버가 재시작되면 사라집니다.
- 한 줄은 200자까지이고, 5초 안에 5개까지만 보낼 수 있습니다.
- 채팅은 전원에게 공개됩니다. 악끼리만 보는 비밀 채팅은 없습니다.

## 규칙

- 멀린과 암살자는 항상 포함됩니다. 퍼시벌, 모르가나, 모드레드, 오베론은 방장이 로비에서 켜고 끕니다.
- 리더가 원정대를 고르고 전원이 찬반 투표합니다. 찬성이 과반이면 원정을 떠나고, 5번 연속 부결되면 악이 이깁니다.
- 원정대원은 성공/실패 카드를 냅니다. 선은 성공만 낼 수 있습니다. 실패가 1장이라도 있으면 원정 실패입니다. (7명 이상의 4번째 원정만 2장)
- 원정이 3번 실패하면 악의 승리입니다. 3번 성공하면 암살자가 멀린을 지목하고, 맞히면 악이 역전합니다.

| 인원 | 선 | 악 | 원정대 인원 (1~5번째) |
|---|---|---|---|
| 5 | 3 | 2 | 2, 3, 2, 3, 3 |
| 6 | 4 | 2 | 2, 3, 4, 3, 4 |
| 7 | 4 | 3 | 2, 3, 3, 4, 4 |
| 8 | 5 | 3 | 3, 4, 4, 5, 5 |
| 9 | 6 | 3 | 3, 4, 4, 5, 5 |
| 10 | 6 | 4 | 3, 4, 4, 5, 5 |

## 파일 구성

| 파일 | 실행 위치 | 역할 |
|---|---|---|
| `server.js` | 서버 | 웹 서버, 소켓 연결, 방 목록 관리 |
| `game.js` | 서버 | 게임 규칙 전부. 플레이어별로 볼 수 있는 정보만 골라 주는 `viewFor` 포함 |
| `public/client.js` | 브라우저 | 서버가 준 화면 데이터를 그리고, 버튼 입력을 서버로 보냄 |
| `public/art.js` | 브라우저 | 역할 초상과 아이콘 (직접 그린 SVG) |
| `public/index.html`, `public/style.css` | 브라우저 | 화면 틀과 중세풍 스타일 |

역할 정보는 서버만 전부 알고 있고, 각 브라우저에는 그 사람이 알아도 되는 것만 보냅니다.

## 디자인

- 양피지 카드, 금박 테두리, 원탁 좌석 배치로 꾸몄습니다. 선은 감청, 악은 진홍입니다.
- 역할 초상 8종과 아이콘은 이 프로젝트용으로 새로 그린 SVG입니다. 보드게임 공식 일러스트는 쓰지 않았습니다.
- 그림은 전부 코드 안의 SVG라 이미지 파일이 없고, 서버 메모리나 용량에 부담을 주지 않습니다.
- 글꼴은 Google Fonts(Cinzel, Gowun Batang)를 불러옵니다. 불러오지 못하면 기기의 기본 명조체로 표시됩니다.

## 로컬 실행

```bash
npm install
npm start
```

http://localhost:3000 에서 확인합니다. 접속 정보를 탭마다 따로 보관하므로, 한 브라우저에서 탭을 5개 열어 혼자 테스트할 수 있습니다.

## Render 배포

1. 이 폴더를 GitHub 저장소로 푸시합니다.
2. Render 대시보드에서 **New → Blueprint** 를 고르고 저장소를 연결합니다. `render.yaml` 설정이 그대로 적용됩니다.
   - 직접 만들 경우: **New → Web Service**, Runtime `Node`, Build Command `npm install`, Start Command `npm start`, Instance Type `Free`

## 재접속

- 게임 중에 연결이 끊겨도 자리는 유지됩니다. 새로고침하거나 화면이 꺼졌다 켜지면 자동으로 원래 자리로 돌아옵니다.
- 탭을 완전히 닫았다면, 같은 방 코드와 **같은 이름**으로 다시 들어오면 끊긴 자리를 되찾습니다.
- 누군가 돌아오지 못해 게임이 멈추면 방장이 **게임 중단**으로 로비에 돌아갈 수 있습니다.

## 알아둘 점

- 15분 동안 접속이 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 1분 가까이 걸립니다.
- 방 정보는 메모리에만 있어서 서버가 재시작되거나 재배포되면 진행 중인 게임은 사라집니다.
- 이름으로 자리를 되찾는 방식은, 끊긴 사람의 이름을 아는 같은 방 사람이 그 자리를 차지할 수도 있다는 뜻입니다. 지인끼리 쓰는 용도를 전제로 한 절충입니다.
